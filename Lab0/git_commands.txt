1) get init - инициализация нового локального репозитория
2) git clone [ссылка] - копирование удаленного репозиторий на компьютер 
3) git status - проверка текущего состояния рабочего дерева и статус 
4) git add [файл] - добавление измененного файла в индекс для следующего коммита
5) git commit -m "[сообщение]" - фиксация или сохранение проиндексированных изменений в истории
6) git push - отправка локальных коммитов в удаленный репозиторий
7) git pull - скачивание
