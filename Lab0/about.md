1) Что такое Git и для чего он используется?
Git - программа или система контроля версий, которая сохраняет историю изменений кода, позволяет откатываться к старым версиям и вести совместную разработку без созданий копий папок
2) В чём разница между централизованными и распределёнными системами контроля версий?
В централизованных вся история проекта хранится только на одном главном сервере ( то есть не работает без интернета). В распределенных системах(Git) полная копия всей истории хранится на компьютере у каждого разработчика, что позволяет работать автономно и защищает от потери данных
3) Что такое репозиторий в Git?
Репозиторий - умная папка проекта, которая загружена в облако GitHub. Она содержит сам код, всю историю его изменений и инструменты для совместной работы
